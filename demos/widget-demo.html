Get started

Always-on support

The widget is available on every page of your site. Users get instant answers sourced directly from your content without leaving the page.

One script tag

Drop a single <script> tag before </body>. No build step, no npm install, no backend changes needed.

Streaming answers

Responses stream word-by-word so users see the answer forming in real time — no waiting for the full response.

Source citations

Every answer links back to the source pages in your knowledge base, so users can verify and explore further.
