Serverless Auto-scaling

All five services run on Cloud Run. The Answerer API scales horizontally under load — new instances spin up in seconds. Each instance serves up to 10 tenants concurrently. No infrastructure to manage.

Multi-tenant Data Isolation

Qdrant gives every tenant a dedicated vector collection — structural isolation with zero cross-tenant query risk. Postgres uses shared tables with enforced tenant_id scoping at the service layer. One platform, many customers.

GCP-Native AI Pipeline

Vertex AI handles both embedding (text-embedding-004) and generation (Gemini 2.0 Flash). All calls are cost-attributed per tenant via GCP labels, enabling precise unit economics per customer.

Async Background Processing

Web crawl and vectorization run in a dedicated Worker service — keeping the API request path fast and clean. Heavy jobs (crawl, chunk, embed) are dispatched asynchronously from a Postgres job queue.

Secure by Default

Storage lives on a private VPC — no public IPs on Qdrant or Cloud SQL. Cloud Run reaches both via Direct VPC Egress and Cloud SQL Proxy. All secrets in Secret Manager. Three distinct auth contexts (service key, admin JWT, widget key).

One-Command Deploy

Each service deploys independently via Cloud Build: build, push to Artifact Registry, and roll out to Cloud Run in a single command. Zero-downtime rollouts; instant rollback to any prior image.
